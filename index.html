🏗️ 4-Layer System Architecture (Chapter 4.2)

The proposed system follows a modular layered architecture separating Presentation, Application Logic, AI/ML Analytics, and Database Storage for Tapi Diploma Engineering College.

1
Presentation Layer
React.js, HTML5, Vanilla CSS & Chart.js. Responsive dashboards for Students, Teachers & Administrators.
2
Application Layer
Node.js / Python backend. Manages business logic, user authentication, RBAC, and report aggregation.
3
AI / ML Layer
Python & Scikit-Learn. Feature selection, performance prediction, risk detection, and study planning.
4
Database Layer
MySQL Relational DB with 13 structured tables maintaining academic data integrity.
✨ Highlights of System Design (Section 4.1)
  • 🔹 Centralized architecture for student academic data storage
  • 🔹 Dedicated dashboards for Students, Teachers, and Administrators
  • 🔹 Automated Attendance formula: (Attended / Total) × 100
  • 🔹 Python AI/ML models for GPA prediction and personalized recommendations
  • 🔹 Early identification of academically at-risk students with multi-factor risk flow
  • 🔹 Graphical visualization across 8 automated exportable academic reports
